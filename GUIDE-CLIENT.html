Comment renommer une photo ?

🖥
Sur Windows Faites un clic droit sur la photo → "Renommer" → tapez le nouveau nom (ex: avant-1.jpg) → appuyez sur Entrée. Attention : gardez bien l'extension .jpg à la fin.
🍎
Sur Mac Cliquez une fois sur le fichier → appuyez sur Entrée → modifiez le nom → appuyez à nouveau sur Entrée pour valider.
📱
Depuis votre téléphone Transférez d'abord les photos sur votre ordinateur (par câble, AirDrop ou email), puis renommez-les depuis l'ordinateur. Le renommage depuis un téléphone est plus compliqué.

Activer le formulaire de contact

Le formulaire de réservation du site utilise Formspree — un service gratuit qui reçoit les messages de vos visiteurs et vous les envoie directement par email. Il y a deux étapes : créer votre compte, puis modifier le fichier index.html pour lui dire d'envoyer les messages chez vous.

Partie A — Créer votre compte Formspree

1
Aller sur formspree.io Ouvrez votre navigateur et rendez-vous sur formspree.io. Cliquez sur "Get Started" ou "Sign Up" (bouton en haut à droite). Inscrivez-vous avec votre adresse email professionnelle (celle où vous voulez recevoir les demandes de clients). Pas de carte bancaire.
2
Confirmer votre email Formspree vous envoie un email de confirmation. Ouvrez-le et cliquez sur le lien pour activer votre compte. Revenez ensuite sur formspree.io et connectez-vous.
3
Créer un nouveau formulaire Une fois connecté, cliquez sur le bouton "+ New Form". Une fenêtre vous demande un nom — tapez quelque chose comme GT Detailing Contact. Cliquez sur "Create Form".
4
Récupérer votre ID unique Formspree affiche maintenant une page avec des instructions. Vous voyez une ligne qui ressemble à :

action="https://formspree.io/f/abcd1234" La partie après le dernier / est votre ID — dans cet exemple c'est abcd1234. Copiez cet ID (sélectionnez-le avec la souris, Ctrl+C).
📬
Plan gratuit suffisant Le plan gratuit Formspree permet 50 soumissions par mois — largement suffisant pour démarrer. Votre ID ressemble à 8 caractères alphanumériques, par exemple xpzgkjrw.

Partie B — Connecter votre site à Formspree

Maintenant que vous avez votre ID, il faut l'insérer dans le fichier index.html. Pas d'inquiétude — c'est une simple recherche/remplacement, pas besoin de savoir coder.

1
Ouvrir index.html avec un éditeur de texte Sur Windows : faites un clic droit sur le fichier index.html → cliquez sur "Ouvrir avec" → choisissez Bloc-notes (ou "Notepad"). Si vous ne le voyez pas, cliquez sur "Choisir une autre application" → cherchez Bloc-notes.

Sur Mac : faites un clic droit (ou Ctrl+clic) sur le fichier → "Ouvrir avec" → TextEdit. Si TextEdit ouvre en mode enrichi, allez dans Format → "Convertir en format texte brut".
2
Rechercher le texte FORMSPREE_ID Une fois le fichier ouvert (vous verrez beaucoup de code), utilisez la fonction Rechercher :

• Sur Windows : Ctrl + H (Rechercher et remplacer)
• Sur Mac : Cmd + Option + F ou Edition → "Rechercher et remplacer"

Dans le champ "Rechercher" (ou "Find"), tapez exactement : FORMSPREE_ID
Dans le champ "Remplacer par" (ou "Replace"), collez votre ID copié à l'étape précédente (ex: abcd1234).
3
Effectuer le remplacement Cliquez sur "Remplacer tout" (ou "Replace All"). Le logiciel vous indique généralement combien de remplacements ont été faits — vous devriez voir 1 remplacement. Si c'est 0, vérifiez l'orthographe (tout en majuscules, pas d'espace).
4
Sauvegarder le fichier Faites Ctrl+S (Windows) ou Cmd+S (Mac). Fermez l'éditeur de texte. Votre fichier index.html est maintenant prêt et connecté à votre compte Formspree.
✅
Vérification rapide Pour confirmer que la modification est bien faite : réouvrez index.html avec Bloc-notes, faites Ctrl+F et cherchez FORMSPREE_ID. Le logiciel doit vous dire qu'il n'a rien trouvé — c'est bon signe, le texte a bien été remplacé.

Étape par étape

1
Se connecter à Hostinger Allez sur hostinger.fr. En haut à droite, cliquez sur "Connexion". Entrez votre email et mot de passe. Vous arrivez sur votre tableau de bord hPanel.
2
Accéder à votre hébergement Sur le tableau de bord, cliquez sur "Hébergement" dans le menu de gauche (ou dans les tuiles principales). Vous voyez votre plan d'hébergement. Cliquez sur le bouton "Gérer" à côté de votre hébergement.
3
Ouvrir le Gestionnaire de fichiers Dans le panneau hPanel de votre hébergement, faites défiler vers le bas. Dans la section "Fichiers", cliquez sur "Gestionnaire de fichiers". Une nouvelle fenêtre s'ouvre (ou un nouvel onglet) avec l'explorateur de fichiers de votre hébergement.
4
Ouvrir le dossier public_html Dans le gestionnaire de fichiers, vous voyez une liste de dossiers. Double-cliquez sur le dossier public_html. C'est le dossier "racine" de votre site — tout ce qui s'y trouve est accessible depuis votre adresse web.

Si vous voyez déjà des fichiers dedans (un ancien site), vous pouvez les supprimer : sélectionnez-les tous (Ctrl+A), clic droit → Supprimer. Attention : cette action est irréversible.
5
Lancer l'upload Toujours dans public_html/, cherchez le bouton "Téléverser des fichiers" (ou icône avec une flèche vers le haut, généralement dans la barre du haut). Cliquez dessus. Une fenêtre de sélection de fichiers s'ouvre sur votre ordinateur.
6
Sélectionner TOUS les fichiers de votre dossier Dans la fenêtre de sélection, naviguez jusqu'à votre dossier GT-Detailing-Site. Sélectionnez tous les fichiers en appuyant sur Ctrl+A (Windows) ou Cmd+A (Mac). Tous les fichiers se surlignent en bleu. Cliquez sur "Ouvrir" (ou "Choisir").

Astuce : si vous avez du mal à sélectionner depuis la fenêtre pop-up, vous pouvez aussi glisser-déposer directement les fichiers depuis votre explorateur de fichiers vers la fenêtre du gestionnaire Hostinger.
7
Attendre la fin du téléversement Hostinger affiche une barre de progression ou une liste de fichiers en cours d'upload. Attendez que tous les fichiers atteignent 100%. Ne fermez pas la fenêtre pendant l'opération. Selon la taille de vos photos, ça peut prendre de 30 secondes à quelques minutes.
8
Vérifier les fichiers uploadés Une fois l'upload terminé, vous voyez tous vos fichiers listés dans public_html/. Vérifiez que vous voyez bien :
index.html   logo.png   equipe.jpg
avant-1.jpg   apres-1.jpg   avant-2.jpg   apres-2.jpg
avant-3.jpg   apres-3.jpg   avant-4.jpg   apres-4.jpg
insta-1.jpg   insta-2.jpg   …   insta-6.jpg Si un fichier manque, re-uploadez-le individuellement.
✓
Ouvrir votre site dans le navigateur Ouvrez Chrome, Safari ou Firefox. Dans la barre d'adresse, tapez votre nom de domaine (ex: www.gtdetailing.mc ou gtdetailing.mc). Appuyez sur Entrée. Votre site s'affiche — félicitations, il est en ligne !

Problèmes fréquents et solutions

Le site s'affiche mais les photos sont vides (cadres gris) Vérifiez deux choses : (1) les photos sont bien dans public_html/ directement — pas dans un sous-dossier. (2) les noms de fichiers sont exacts, sans majuscule ni espace. Ex: Avant-1.jpg ne fonctionne pas, il faut avant-1.jpg. Rafraîchissez avec Ctrl+Maj+R (vide le cache).
Le formulaire dit "erreur" quand on l'envoie Vous n'avez pas remplacé FORMSPREE_ID dans index.html, ou votre compte Formspree n'est pas confirmé. Reprenez la Section 02 depuis le début, puis re-uploadez le fichier index.html sur Hostinger.
Le nom de domaine ne pointe pas vers le site Si votre domaine est tout nouveau ou vient d'être modifié, il faut parfois attendre 24 à 48 heures que les DNS se propagent partout dans le monde. C'est normal. En attendant, vous pouvez accéder au site via l'adresse IP fournie par Hostinger dans votre panneau.
La page affiche une erreur 403 ou "Accès interdit" Le fichier index.html est peut-être manquant ou mal orthographié (ne pas mettre Index.html avec majuscule). Vérifiez dans le Gestionnaire de fichiers qu'il s'appelle bien index.html en minuscules.
Votre domaine n'est pas encore relié à Hostinger ?

Si vous avez acheté votre domaine ailleurs (OVH, Ionos, Namecheap…), voici comment le connecter :

1
Récupérer les nameservers Hostinger Dans hPanel → Hébergement → votre plan → onglet "Domaines". Vous voyez les nameservers Hostinger, ressemblant à ns1.hostinger.com et ns2.hostinger.com.
2
Les entrer chez votre registrar Connectez-vous au panneau où vous avez acheté le domaine. Cherchez les paramètres DNS ou "Nameservers". Remplacez les nameservers existants par ceux de Hostinger. Sauvegardez.
3
Attendre la propagation La propagation DNS prend entre 2h et 48h selon les cas. Après ce délai, votre domaine pointe vers Hostinger et votre site s'affiche.
Si votre domaine a été acheté directement chez Hostinger, cette étape n'est pas nécessaire — tout est déjà relié automatiquement.
