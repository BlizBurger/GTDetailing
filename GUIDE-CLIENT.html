01

Préparer ses photos

Le site affiche vos photos automatiquement — mais il les cherche par leur nom exact. La seule chose à faire : renommer vos photos avant de les uploader.

💡
Principe simple Votre photo s'appelle IMG_4521.jpg sur votre téléphone ? Renommez-la en avant-1.jpg et le site l'affiche automatiquement à la bonne place. C'est tout.

Comment renommer une photo ?

🖥
Sur Windows Faites un clic droit sur la photo → "Renommer" → tapez le nouveau nom (ex: avant-1.jpg) → appuyez sur Entrée. Attention : gardez bien l'extension .jpg à la fin.
🍎
Sur Mac Cliquez une fois sur le fichier → appuyez sur Entrée → modifiez le nom → appuyez à nouveau sur Entrée pour valider.
📱
Depuis votre téléphone Transférez d'abord les photos sur votre ordinateur (par câble, AirDrop ou email), puis renommez-les depuis l'ordinateur. Le renommage depuis un téléphone est plus compliqué.

02

Recevoir les emails du formulaire

Le formulaire de réservation du site utilise Formspree (service gratuit) pour envoyer les demandes directement dans votre boîte mail.

1
Créer un compte gratuit Rendez-vous sur formspree.io et inscrivez-vous avec votre adresse email professionnelle.
2
Créer un nouveau formulaire Cliquez sur "New Form" → donnez-lui un nom (ex: "GT Detailing Contact") → validez.
3
Copier l'ID du formulaire Vous verrez une URL du type https://formspree.io/f/abcd1234. Copiez la partie en gras (ex: abcd1234).
4
L'intégrer dans le site Dans le fichier index.html, faites Ctrl+F → recherchez FORMSPREE_ID → remplacez par votre ID. Sauvegardez.
📬
Plan gratuit suffisant Le plan gratuit Formspree permet 50 soumissions/mois, ce qui est largement suffisant pour commencer. Pas de carte bancaire requise.
03

Mettre le site en ligne sur Hostinger

Une fois tous vos fichiers prêts et renommés, voici comment les uploader sur Hostinger en moins de 5 minutes.

1
Connectez-vous à Hostinger Allez sur hostinger.fr → Mon compte → Hébergement → sélectionnez votre hébergement.
2
Ouvrir le Gestionnaire de fichiers Dans votre panneau hPanel, cliquez sur "Gestionnaire de fichiers" (ou File Manager).
3
Naviguer dans public_html Dans le gestionnaire, double-cliquez sur le dossier public_html. C'est là que se trouvent tous les fichiers de votre site.
4
Supprimer les anciens fichiers (si besoin) Si un ancien site est déjà en ligne, supprimez l'ancien index.html avant d'uploader le nouveau.
5
Uploader tous vos fichiers Cliquez sur "Téléverser" (ou Upload) → sélectionnez tous vos fichiers d'un coup (index.html + toutes les images). Attendez la fin du chargement.
6
Vérifier le résultat Ouvrez votre navigateur et tapez votre nom de domaine. Votre site est en ligne !
⚠️
Tous les fichiers dans le même dossier Le fichier index.html et toutes vos images (logo.png, avant-1.jpg…) doivent être au même niveau dans public_html/, pas dans des sous-dossiers.

05

Modifier le contenu plus tard

Si vous souhaitez modifier un texte, un prix ou une photo, voici comment faire :

→
Modifier un texte ou un prix Ouvrez index.html avec Bloc-notes (Windows) ou TextEdit (Mac). Faites Ctrl+F, cherchez le texte à changer, modifiez-le, sauvegardez, re-uploadez sur Hostinger.
→
Changer une photo Renommez votre nouvelle photo avec le même nom (ex: avant-1.jpg), puis re-uploadez-la sur Hostinger. Elle remplace automatiquement l'ancienne.
→
Pour tout autre modification complexe Contactez-nous directement. Nous intervenons rapidement pour toute mise à jour de contenu, nouveau service, changement de tarif ou ajout de section.
