Préparer ses photos

Le site affiche vos photos automatiquement — mais il les cherche par leur nom exact. La seule chose à faire : rassembler toutes vos photos dans le même dossier que le fichier index.html, avec les bons noms.

📂 Créez un dossier sur votre ordinateur — mettez TOUT dedans
Dossier : GT-Detailing-Site /

☝️ Tous les fichiers au même niveau — pas dans des sous-dossiers
💡
Comment ça fonctionne Votre photo s'appelle IMG_4521.jpg sur votre téléphone ? Renommez-la en avant-1.jpg, mettez-la dans le dossier, et le site l'affiche automatiquement à la bonne place. C'est tout.

Comment renommer une photo ?

🖥
Sur Windows Faites un clic droit sur la photo → "Renommer" → tapez le nouveau nom (ex: avant-1.jpg) → appuyez sur Entrée. Attention : gardez bien l'extension .jpg à la fin.
🍎
Sur Mac Cliquez une fois sur le fichier → appuyez sur Entrée → modifiez le nom → appuyez à nouveau sur Entrée pour valider.
📱
Depuis votre téléphone Transférez d'abord les photos sur votre ordinateur (par câble, AirDrop ou email), puis renommez-les depuis l'ordinateur. Le renommage depuis un téléphone est plus compliqué.

02

Recevoir les emails du formulaire

Le formulaire de réservation du site utilise Formspree (service gratuit) pour envoyer les demandes directement dans votre boîte mail.

1
Créer un compte gratuit Rendez-vous sur formspree.io et inscrivez-vous avec votre adresse email professionnelle.
2
Créer un nouveau formulaire Cliquez sur "New Form" → donnez-lui un nom (ex: "GT Detailing Contact") → validez.
3
Copier l'ID du formulaire Vous verrez une URL du type https://formspree.io/f/abcd1234. Copiez la partie en gras (ex: abcd1234).
4
L'intégrer dans le site Dans le fichier index.html, faites Ctrl+F → recherchez FORMSPREE_ID → remplacez par votre ID. Sauvegardez.
📬
Plan gratuit suffisant Le plan gratuit Formspree permet 50 soumissions/mois, ce qui est largement suffisant pour commencer. Pas de carte bancaire requise.
03

Mettre le site en ligne sur Hostinger

Une fois votre dossier prêt (section 01), vous allez copier son contenu dans Hostinger. C'est exactement comme copier-coller des fichiers, mais sur internet.

Votre ordinateur
📁 GT-Detailing-Site /
  📄 index.html
  🖼 logo.png
  🖼 avant-1.jpg
  🖼 apres-1.jpg
  🖼 insta-1.jpg
  … etc.
➜
Hostinger — public_html /
📄 index.html
🖼 logo.png
🖼 avant-1.jpg
🖼 apres-1.jpg
🖼 insta-1.jpg
… etc.
☝️
À retenir Sur Hostinger, vous uploadez le contenu de votre dossier (pas le dossier lui-même). Tous les fichiers doivent se retrouver directement dans public_html/, côte à côte.
1
Connectez-vous à Hostinger Allez sur hostinger.fr → cliquez sur votre compte → Hébergement → sélectionnez votre hébergement.
2
Ouvrir le Gestionnaire de fichiers Dans le panneau hPanel, cherchez et cliquez sur "Gestionnaire de fichiers". Une nouvelle fenêtre s'ouvre avec tous les dossiers de votre hébergement.
3
Ouvrir le dossier public_html Double-cliquez sur le dossier nommé public_html. C'est dans ce dossier que votre site doit atterrir. Tout ce que vous mettez ici est visible sur internet.
4
Supprimer l'ancien index.html si nécessaire Si un ancien site existe, cliquez droit sur l'ancien index.html → Supprimer. Gardez les autres fichiers si vous en avez besoin.
5
Uploader tous vos fichiers d'un coup Cliquez sur le bouton "Téléverser" / "Upload" (en haut à gauche en général) → une fenêtre s'ouvre → sélectionnez tous vos fichiers en même temps (Ctrl+A ou Cmd+A pour tout sélectionner) → cliquez Ouvrir → attendez que la barre de progression atteigne 100%.
6
Vérifier que les fichiers sont bien là Dans le gestionnaire, vous devez voir index.html, logo.png, avant-1.jpg… tous listés côte à côte dans public_html/.
✓
Taper votre nom de domaine dans le navigateur Ouvrez Chrome ou Safari, tapez votre adresse web (ex: www.gtdetailing.mc). Votre site s'affiche — il est en ligne !
⚠️
Le site s'affiche mais les photos sont vides ? Vérifiez que vos photos sont bien dans public_html/ et pas dans un sous-dossier. Vérifiez aussi que les noms sont exacts (pas de majuscule, pas d'espace). Rafraîchissez la page avec Ctrl+F5.

05

Modifier le contenu plus tard

Si vous souhaitez modifier un texte, un prix ou une photo, voici comment faire :

→
Modifier un texte ou un prix Ouvrez index.html avec Bloc-notes (Windows) ou TextEdit (Mac). Faites Ctrl+F, cherchez le texte à changer, modifiez-le, sauvegardez, re-uploadez sur Hostinger.
→
Changer une photo Renommez votre nouvelle photo avec le même nom (ex: avant-1.jpg), puis re-uploadez-la sur Hostinger. Elle remplace automatiquement l'ancienne.
→
Pour tout autre modification complexe Contactez-nous directement. Nous intervenons rapidement pour toute mise à jour de contenu, nouveau service, changement de tarif ou ajout de section.
