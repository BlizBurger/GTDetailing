GT DETAILING — GUIDE DE PERSONNALISATION

Tout ce qu'il faut faire pour mettre à jour votre site. En 3 étapes simples, sans toucher au code.

✅
Comment ça marche : vous n'avez que 2 fichiers à modifier — config.js pour les textes et liens, et vos images renommées selon les règles ci-dessous. Rien d'autre.
① Préparer les images ② Remplir config.js ③ Uploader sur Hostinger ④ Activer les formulaires ⑤ Google Maps ⑥ Avis Google

2

Remplir le fichier config.js

C'est le seul fichier texte à modifier. Ouvrez-le avec le Bloc-notes (Windows) ou TextEdit (Mac). Remplacez les valeurs entre guillemets. Sauvegardez.

Contenu de config.js — modifiez les parties en vert

/* VOS RÉSEAUX SOCIAUX */

var INSTAGRAM = "https://www.instagram.com/votrecompte";
var TIKTOK = "https://https://www.tiktok.com/@gtdetailingmc?is_from_webapp=1&sender_device=pc";
var FACEBOOK = ""; // laissez "" si pas de page Facebook

/* LIEN VERS VOS AVIS GOOGLE */
var GOOGLE_AVIS_URL = "https://maps.google.com/...votrelien...";

/* FORMULAIRES — copiez votre ID Formspree ici (voir étape 4) */
var FORMSPREE_ID = "abc123def";

/* VOS AVIS CLIENTS — remplacez texte, prénom, ville */
var AVIS = [
  { texte: "Votre premier vrai avis client ici...", prenom: "Marc", ville: "Monaco" },
  { texte: "Deuxième avis...", prenom: "Sophie", ville: "Nice" },
  // ajoutez autant d'avis que vous voulez
];

/* NOMS DES VÉHICULES DANS LES SLIDERS */
var SLIDERS = [
  { titre: "Ferrari 488", tag: "Traitement céramique" },
  { titre: "Porsche 911", tag: "Correction peinture" },
  { titre: "Range Rover", tag: "Détailing complet" },
  { titre: "Lamborghini", tag: "Lavage premium" },
];

/* GOOGLE MAPS — voir étape 5 */
var GOOGLE_MAPS_EMBED = "";
3

Uploader sur Hostinger

Une seule fois. Ensuite, pour mettre à jour une image ou un texte, vous re-uploadez juste le fichier modifié.

Étapes dans le Gestionnaire de fichiers Hostinger

1

Connectez-vous sur hpanel.hostinger.com → votre hébergement → Gérer → Gestionnaire de fichiers

2

Ouvrez le dossier public_html

3

Cliquez Télécharger ⬆ et sélectionnez tous les fichiers d'un coup :

📄 index.html
📄 config.js
🖼️ logo.png
🖼️ equipe.jpg
🖼️ avant-1.jpg  /  apres-1.jpg
🖼️ avant-2.jpg  /  apres-2.jpg
🖼️ avant-3.jpg  /  apres-3.jpg
🖼️ avant-4.jpg  /  apres-4.jpg
🖼️ insta-1.jpg  …  insta-6.jpg
✅ Une fois ces fichiers uploadés, votre site est en ligne et complet. Ouvrez votredomaine.com pour vérifier.
4

Activer les formulaires Gratuit

Par défaut les formulaires ouvrent votre client mail. Pour recevoir les demandes directement dans votre boîte email, configurez Formspree (5 minutes, gratuit jusqu'à 50 emails/mois).

Configuration en 4 clics

1

Allez sur formspree.io → créer un compte avec albert@gtdetailingmc.com

2

Cliquez + New Form → donnez un nom (ex: "GT Detailing")

3

Copiez l'ID du formulaire (les 8 lettres dans l'URL, ex: xpzgkwqr)

4

Collez cet ID dans config.js à la ligne var FORMSPREE_ID = "..." → sauvegardez et ré-uploadez config.js

5

Intégrer la carte Google Maps

Obtenir le code iframe

1.

Allez sur google.fr/maps → cherchez "Monaco" ou votre adresse

2.

Cliquez Partager → onglet "Intégrer une carte" → "Copier le HTML"

3.

Le code copié ressemble à :
<iframe src="https://www.google.com/maps/embed?pb=..." ...>
Prenez uniquement la valeur de src (le lien entre les guillemets)

4.

Collez ce lien dans config.js à la ligne var GOOGLE_MAPS_EMBED = "..."

6

Mettre vos vrais avis Google

Deux options :

Option A — Manuel Simple

Copiez-collez vos avis Google dans config.js, section var AVIS = [...]. Ajoutez autant de cartes que vous voulez.

👍Parfait pour commencer. Vous mettez à jour quand vous avez de nouveaux avis.

Option B — Automatique Recommandé

Elfsight Google Reviews affiche vos vrais avis en temps réel, mis à jour automatiquement.

1. Allez sur elfsight.com (gratuit jusqu'à 200 vues/mois) 2. Cherchez "Google Reviews" → configurez 3. Copiez le code qu'ils donnent 4. Collez-le dans Hostinger à la place du carrousel d'avis
